# StartWebProject
## Общее описание
Проект содержит два независимых учебных подпроекта:
* форму авторизации;
* страницу с размещением карточек астероидов.

Подпроекты запускаются независимо друг от друга и используют разные порты. Они не взаимодействуют между собой.
Данный проект является учебным и находится в незавершённом состоянии. Основной целью разработки было изучение принципов веб-программирования и связанных с ними технологий.
Далее будут приведены инструкции для работы в Windows 10-11.

## Описание формы авторизации
Подпроект формы авторизации содержится в корневой папке проекта.
В рамках подпроекта реализовано небольшое серверное приложение на Node.js с использованием Express. Сервер предоставляет HTML-страницу с формой и обрабатывает отправленные с неё данные.
Полученные данные сохраняются в файл `data.txt`.

### Используемые технологии
* **Node.js** -  среда выполнения JavaScript;
* **Express** -  фреймворк для разработки серверной части;
* **JavaScript** - язык программирования;
* **HTML** - разметка страницы;
* **CSS** - оформление страницы.

## Описание страницы с астероидами
Подпроект страницы с астероидами содержится в каталоге `./dss-app`.
Приложение представляет собой клиентскую часть, разработанную на React. В приложении реализованы страницы и компоненты для отображения карточек астероидов.

### Используемые технологии
* **React 18** - библиотека для разработки пользовательского интерфейса;
* **TypeScript** - язык программирования и статическая типизация;
* **JavaScript** - используется в отдельных компонентах проекта;
* **React Router DOM** - маршрутизация между страницами приложения;
* **CSS Modules** - стилизация компонентов;
* **ESLint** - статический анализ исходного кода;
* **Prettier** - автоматическое форматирование исходного кода.

## Инструкция по установке
### Предварительная установка Node.js
Для работы обоих подпроектов требуется Node.js.
1. Установите Node.js с [официального сайта](https://nodejs.org/). При установке можно оставить стандартные параметры.
2. Для проверки установки откройте командную строку и выполните:
```cmd
node --version
```
```cmd
npm --version
```
При успешной установке обе команды должны вывести номера версий Node.js и npm.

### Установка формы авторизации
1. Откройте командную строку.
2. Перейдите в корневой каталог проекта:
```cmd
cd ./[Название папки проекта]
```
При переходе в каталог, расположенный на другом диске, используйте параметр `/d`, например:
```cmd
cd /d D:\[Название папки проекта]
```
3. Установите зависимости:
```cmd
npm install
```
После завершения установки подпроект готов к запуску.

### Установка страницы с астероидами
1. Откройте командную строку.
2. Перейдите в каталог `dss-app`:
```cmd
cd ./[Название папки проекта]/dss-app
```
При переходе в каталог, расположенный на другом диске, используйте параметр `/d`, например:
```cmd
cd /d D:\[Название папки проекта]\dss-app
```
3. Установите зависимости:
```cmd
npm ci --legacy-peer-deps
```
Использование параметра `--legacy-peer-deps` необходимо для корректной установки зависимостей данного учебного проекта из-за конфликта версий `eslint` и пакетов `react-scripts`.

## Запуск проекта
Подпроекты можно запускать как одновременно, так и по отдельности. Ниже приведена инструкция для каждого из них.
### Запуск формы авторизации
1. Откройте командную строку.
2. Перейдите в корневой каталог проекта:
```cmd
cd ./[Название папки проекта]
```
3. Запустите сервер:
```cmd
npm run start:dev
```
4. При успешном запуске в консоли появится сообщение:
```text
Example app listening on port 3000
```
5. После этого форма авторизации будет доступна по адресу:
```text
http://localhost:3000
```
Для завершения работы сервера нажмите `Ctrl+C` в окне командной строки.

### Запуск страницы с астероидами
1. Откройте командную строку.
2. Перейдите в каталог подпроекта:
```cmd
cd ./[Название папки проекта]/dss-app
```
3. Запустите приложение:
```cmd
npm start
```
4. Если порт `3000` уже занят, React предложит запустить приложение на другом доступном порту. В случае выбора предложенного порта приложение будет запущено.
5. При успешном запуске в консоли появится сообщение о том, что приложение доступно в браузере. При использовании порта `3001` адрес будет:
```text
http://localhost:3001
```
6. После запуска приложение можно открыть в браузере по указанному адресу.
Для завершения работы приложения нажмите `Ctrl+C` в окне командной строки.

### Дополнительно
При одновременном запуске подпроектов необходимо учитывать используемые ими порты.
По умолчанию форма авторизации использует порт `3000`. Если сначала запустить страницу с астероидами, React обнаружит занятый порт `3000` и предложит использовать порт `3001`.
Если после этого попытаться запустить форму авторизации, её сервер всё равно будет пытаться использовать порт `3000`. Автоматического переноса Express-приложения на другой порт в проекте не предусмотрено.
Поэтому при одновременной работе рекомендуется:
1. сначала запустить форму авторизации на порту `3000`;
2. запустить страницу с астероидами и согласиться на использование порта `3001`.

В результате получится следующее распределение портов:
| Подпроект              |   Порт | Адрес                   |
| ---------------------- | -----: | ----------------------- |
| Форма авторизации      | `3000` | `http://localhost:3000` |
| Страница с астероидами | `3001` | `http://localhost:3001` |

## Инструкция по удалению
Удаление проекта состоит из двух частей: удаление файлов проекта и, при необходимости, удаление установленных инструментов и зависимостей.

### Удаление зависимостей проекта
Если необходимо удалить только установленные зависимости, не удаляя исходный код проекта:
1. Откройте корневой каталог проекта.
2. Удалите каталог `node_modules`.
3. Перейдите в каталог `dss-app`.
4. Удалите каталог `node_modules`.
Удаление `node_modules` не удаляет исходный код проекта. При необходимости зависимости можно установить заново с помощью команд, приведённых в разделе [Инструкция по установке](#инструкция-по-установке).

### Полное удаление проекта
Для полного удаления проекта достаточно удалить папку проекта целиком.
Перед удалением убедитесь, что серверы и приложение остановлены. Если какой-либо из подпроектов запущен, нажмите `Ctrl+C` в соответствующем окне командной строки.
После этого удалите папку проекта обычными средствами Windows.

### Удаление Node.js
Если Node.js больше не требуется для других проектов, его можно удалить вместе с установленным программным обеспечением.
1. Закройте все окна командной строки и приложения, использующие Node.js.
2. Откройте **Панель управления -> Программы -> Программы и компоненты**.
3. Найдите в списке `Node.js`.
4. Выберите приложение и нажмите **Удалить**.
5. Следуйте инструкциям мастера удаления.
После удаления Node.js команды `node` и `npm` перестанут быть доступны в командной строке.

Для проверки удаления откройте новое окно командной строки и выполните:
```cmd
node --version
```
и:
```cmd
npm --version
```
Если Node.js удалён корректно, Windows сообщит, что команда `node` или `npm` не найдена.
